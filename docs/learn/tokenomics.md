# 📊 SUITE Tokenomics

**How the SUITE token economy works**

---

## Core Mechanics

### Minting (ETH → SUITE)
Deposit ETH into the Treasury → Receive SUITE tokens at current rate.

### Burning (SUITE → ETH)
Burn SUITE tokens → Receive proportional ETH from Treasury.

---

## Floor Price Guarantee

SUITE has a guaranteed floor price because every token is backed by ETH in the Treasury:

```
Floor Price = Treasury ETH ÷ Total SUITE Supply
```

You can **always** redeem SUITE for at least the floor price in ETH.
