# ⚙️ How SUITE Works

**A high-level overview of the SUITE ecosystem**

---

## The Flow

```
Idea → Build → Publish → Earn
```

1. **You have an idea** for an app
2. **Describe it to Cadence AI** — or build it yourself
3. **Publish to the SUITE App Store**
4. **Users pay in SUITE tokens** to use your app
5. **You earn** 70% of every transaction

---

## Key Components

### 🏦 Treasury
Smart contract holding ETH that backs all SUITE tokens. When you deposit ETH, you mint SUITE. When you burn SUITE, you get ETH back.

### 🪙 SUITE Token
Utility token used across all apps. Always backed by ETH — guaranteed floor price.

### 🤖 Cadence AI
Tell it what you want to build in natural language. It generates the code.

### 🔨 FORGE Bot
Discord bot for queuing prompts, managing apps, and notifications.

### 👁️ AI Fleet
Automated system that processes prompts 24/7 across multiple IDEs.
