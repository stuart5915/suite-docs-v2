## 🏦 Treasury Architecture

**Smart contract that holds ETH backing all SUITE tokens.**

<div className={styles.systemLayout}>
  <div className={styles.systemDiagram}>
    <img src="/img/diagrams/treasury.png" alt="Treasury" />
  </div>
  <div className={styles.systemDetails}>
    <details>
      <summary>Mint (ETH → SUITE)</summary>
      <p>Deposit ETH into Treasury, receive SUITE tokens at current exchange rate.</p>
    </details>
    <details>
      <summary>Burn (SUITE → ETH)</summary>
      <p>Send SUITE back to Treasury, receive proportional ETH from the pool.</p>
    </details>
    <details>
      <summary>Floor price guarantee</summary>
      <p>Floor = Treasury ETH ÷ Total SUITE Supply. Always redeemable at this rate.</p>
    </details>
    <details>
      <summary>Proportional shares</summary>
      <p>Treasury uses share-based accounting to ensure it's always solvent.</p>
    </details>
  </div>
</div>

## 🔒 Security Model

- **Isolated repos** — Each app in its own repository
- **No cross-access** — Apps can't modify other apps
- **Prompt filtering** — Dangerous commands blocked
- **Human approval** — Critical operations require review
