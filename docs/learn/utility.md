# ⚡ SUITE Utility

**What you can do with SUITE tokens**

---

## Core Utility

### 🛒 Pay for Apps
SUITE is the currency for all apps in the ecosystem. Purchase premium features, unlock content, and access tools.

### 🚀 Boost Apps
Pay to increase visibility of your apps in the App Store. Higher boosts = more discovery.

### 🗳️ Vote
Staked SUITE gives you voting power on:
- Giving Fund allocations
- Ecosystem proposals
- Feature priorities

---

## Earning with SUITE

### 💰 Build Apps
Developers earn 70% of app transaction revenue.

### 🌱 Stake
Lock SUITE to earn yield from ecosystem fees.

### 👥 Refer
Earn rewards when referred users deposit.

---

## Token Mechanics

| Action | Effect |
|--------|--------|
| Mint | ETH → SUITE (adds to Treasury) |
| Burn | SUITE → ETH (proportional withdrawal) |
| Stake | Lock SUITE → Earn yield + voting |
| Pay | SUITE → App → Developer receives 70% |

---

## Floor Price Guarantee

Every SUITE token is backed by ETH in the Treasury:

```
Floor Price = Treasury ETH ÷ Total SUITE Supply
```

This means SUITE always has real value you can redeem.
