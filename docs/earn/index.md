# 💰 How to Earn with SUITE

**Multiple ways to generate income in the ecosystem**

---

## Earning Methods

### 🛠️ Build Apps (70% of revenue)
Create apps that accept SUITE payments. Earn 70% of every transaction.

- Build with Cadence AI
- Publish to App Store
- Users pay SUITE to use features
- You receive 70% automatically

### 🌱 Stake SUITE (Yield)
Lock your SUITE tokens to earn yield from ecosystem fees.

- Stake for 30-365 days
- Longer stakes = higher yield
- Compound automatically
- Also earn voting power

### 👥 Refer Users
Earn rewards when users you invite deposit ETH.

- Share your referral link
- New user deposits ETH
- You earn a percentage

### 📝 Review Apps
Community reviewers earn SUITE for evaluating submissions.

- Join the Reviewer role
- Test submitted apps
- Vote approve/reject
- Earn per review
